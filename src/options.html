Jev X Highlighter 設定

Jev API キー

TypeSafe のコンソール (console.typesafe.ai) で発行したキーを入力します。このブラウザにだけ保存され、同期されません。

判定

カテゴリ

「判定の説明」は Jev への質問文です。英語のほうが精度が出やすいとされています。キーワード・アカウントに一致したツイートは Jev の判定を待たずに強調します。種類を「ミュート」にすると、該当したツイートを薄く・折りたたみ・非表示にします (ポップアップで切り替え)。

判定ログ (👍 / 👎)

X で押した 👍 / 👎 の記録です。カテゴリごとの正解率でしきい値を見直せます。「例に追加」を押すと、そのツイートをカテゴリの「該当する例 / 該当しない例」に追記します (追記後に「保存」を押すと反映されます)。
