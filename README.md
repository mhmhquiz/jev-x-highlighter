# Jev X Highlighter

X (x.com) のタイムラインで、AI や VRChat など興味のある話題のツイートを [Jev (TypeSafe AI)](https://docs.typesafe.ai/) で**意味で判定**して強調表示する Chrome 拡張です。

- キーワードではなく、自然文で書いたカテゴリの説明で判定します (「AI」という語がなくても AI の話題を拾い、「AIR」「愛」には反応しません)。
- X のタイムライン API の応答を横取りして、ツイートが画面に描画される前に判定を始めます。
- 広告ツイートは判定せず無視します。

要件は [REQUIREMENTS.md](REQUIREMENTS.md) を参照してください。

## インストール (開発版)
1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします。
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選びます。
3. 拡張のアイコン →「詳細設定」を開き、TypeSafe のコンソール (https://console.typesafe.ai/keys) で発行した API キーを保存します。
4. x.com を開く (開いていた場合は再読み込み) と、判定されたツイートに色とバッジが付きます。

## 使い方
- **強調**: 確率がしきい値 (既定 0.8、カテゴリごとにも設定可) 以上ならカテゴリ色で強調し、弱いしきい値 (既定 0.5) 以上なら「?」付きで細く強調します。強調の背景は確率が高いほど濃くなります。ツイート右上に「AI · 画像生成」のような小さなタグが出て、マウスを乗せると各カテゴリの確率と 👍 / 👎 ボタンが出ます。
- **小分類**: カテゴリごとに小分類 (例: AI → 画像・動画生成 / LLM・チャット / ツール・使い方…) を設定すると、タグにどの小分類かが出ます。
- **💡 有益**: 情報の多いツイート (ニュース・手順・コツなど) に 💡 を付けます。「有益さが低いツイートは弱い強調にする」も選べます。
- **ミュート**: カテゴリの種類を「ミュート」にすると、該当したツイートを薄く / 折りたたみ / 非表示にします (初期カテゴリ「炎上・政治」は OFF で入っています)。
- **見逃しリスト**: ポップアップの「見逃しリストを開く」で、強調されたツイートの一覧をサイドパネルに出します。カテゴリ・💡・未読・文字で絞り込めます。
- **👍 / 👎**: タグにマウスを乗せると出るボタンで判定の正誤を記録します。詳細設定の「判定ログ」でカテゴリごとの正解率を見られ、「例に追加」でそのツイートをカテゴリの「該当する例 / 該当しない例」に追記できます。
- **対象外のツイート**: ポップアップで「そのまま / 薄く表示 / 折りたたみ / 非表示」を切り替えます。
- **カテゴリ**: 詳細設定で追加・編集・並べ替えします。「判定の説明」が Jev への質問文です。「必ず該当するキーワード / アカウント」は Jev の判定を待たずに強調します。
- **費用**: ポップアップに今日の判定件数と推定費用が出ます。1 日の上限 (既定 3000 件) を超えると判定を止めます。小分類と有益さは同じリクエストに入るので、件数は増えません (トークンは少し増えます)。

## 構成
| ファイル | 役割 |
|---|---|
| `src/inject.js` | ページ側 (MAIN world) で fetch / XHR をフックし、X の GraphQL 応答を横取りする |
| `src/x-parser.js` | GraphQL 応答からツイート (本文・投稿者・引用・リンクタイトル・画像 alt・ハッシュタグ) を取り出す。広告は除く |
| `src/content.js` | ツイートを service worker に判定させ、描画されたツイートに強調を付ける |
| `src/background.js` | Jev API の呼び出し、同時実行数の制御、キャッシュ、利用量の記録 |
| `src/jev.js` | Jev へのリクエストの組み立てと呼び出し (PoC と共用) |
| `src/options.*` / `src/popup.*` | 設定画面 (判定ログを含む) とポップアップ |
| `src/sidepanel.*` | 見逃しリスト (サイドパネル) |
| `src/defaults.js` | 初期設定と設定の読み書き (`chrome.storage.local`) |

## 開発
```bash
npm test
```

### PoC (日本語の精度と速度の測定)
`poc/samples.example.json` と同じ形式で、自分のタイムラインから集めたツイートと正解ラベルを `poc/samples.json` に置きます (Git には含めません)。API キーを環境変数 `TYPESAFE_API_KEY` に入れて実行します。

```bash
npm run poc -- poc/samples.json
```

「1 件 1 リクエスト」と「20 件まとめて 1 リクエスト」の精度と応答時間を表示します。

## 注意
- 判定のため、ツイートの本文・投稿者名・引用・リンクタイトル・画像の代替テキストを TypeSafe の API に送信します。
- API キーは `chrome.storage.local` に保存され、同期されません。リポジトリには含めないでください。
- X の画面や API の構造が変わると動かなくなることがあります。その場合も X の表示は壊さず、強調が付かなくなるだけです。
